# Privacy Policy — Replay Fix for Microsoft Clarity

_Last updated: 2026-11-13_

Replay Fix for Microsoft Clarity ("the extension") does not collect, store, transmit, sell, or share any personal or user data.

**What the extension does**
- It runs only on `https://clarity.microsoft.com/*`.
- It replaces the page's `getComputedStyle` function with a version that skips one redundant style lookup inside Clarity's replay view. All of this happens locally in your browser.

**What the extension stores**
- When you pause the fix for a tab, a single flag is saved in that tab's own sessionStorage on clarity.microsoft.com. It is deleted when the tab is closed and is never sent anywhere.

**What the extension does not do**
- It does not read, record, or transmit the content of Clarity pages, your recordings, your account, or your browsing activity.
- It makes no network requests of its own and loads no remote code.
- It uses no analytics, tracking, or advertising.

**Third parties**
- No data is shared with any third party, including Microsoft or Google.

**Changes**
- If this policy changes, the updated version will be published at this same address with a new "Last updated" date.

**Contact**
- Questions can be raised by opening an issue in this extension's GitHub repository.
